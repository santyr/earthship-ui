# Bedroom WH32M commissioning

The operator supplied a powered 915 MHz Ambient Weather WH32M. The existing
receiver decodes it as `AmbientWeather-WH31E`, ID **223**, rather than WH32B.
The operator's displayed 71.4°F matched the naturally received 71.42°F.
Battery removal stopped ID 223 at 16:37:22 MDT while the other sensors
continued; reinsertion resumed the same ID at 16:42:00. No ID was guessed
from the product name or substituted from a held numeric Item.

Ambient documents an initial 30-second transmission period followed by up
to ten minutes of clock synchronization without weather transmissions:
[WS-2700 manual, section 3.4.4](https://ambientweather.com/mwdownloads/download/link/id/598/).
This accounts for the commissioning pause; it does not qualify held readings.
