# Original measured-weather source context

The pure frozen context retains exact original receiver envelopes, policy texts, digests, explicit stream bindings and availability clocks for the existing radiation and rain sources. It uses the established radiation/v2 and rain/v1 validators. Radiation/v1 lacks fault visibility and stays unavailable for qualified point observations. Missing, malformed, expired or independently unbound sources do not discard the valid companion source.

The three point roles are received lux, lux-derived radiation proxy and original cumulative rain counter. Receiver/decoder time is preserved without inventing a sensor measurement timestamp. Each derived reference has a role-specific identity, original source/policy parents and original expiry. The proxy is not calibrated irradiance; the counter is not rainfall rate or a qualified daily total. Software stream epochs are not physical hardware epochs. Calibration, rain rate, physical effects and automatic actuation remain unqualified.
