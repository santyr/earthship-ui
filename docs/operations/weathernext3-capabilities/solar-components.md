It is not installed or selected in production.

WeatherNext's one-hour SSRD and FDIR fields carry total and direct **horizontal** energies. The field mapping and primary sources are recorded in [solar-semantics.json](solar-semantics.json). The new forcing packet `earthship-weathernext-native-forecast/v2` retains each original energy, native cell, ending interval, source digest and acquisition clocks. Validation replays the original provider capsule. The default v1 producer, its original row meanings and numerical functions remain available and unchanged.

The reconstruction normalizes a constant nonnegative daylight DNI shape over complete retained five-minute geometry, so its horizontal integral equals FDIR. Diffuse energy is SSRD minus FDIR, distributed over the same daylight support. It conserves the raw hourly energies before applying the existing terrain mask to direct radiation. Diffuse sky view remains unmodeled. Missing direct data, substantially crossed energies, low-sun bounds and missing full source-hour geometry each produce a named total-only fallback. Missing geometry inside the requested prediction window withholds that projection. A partial remaining hour never receives the complete original hour's energy.

`household_pv_components.py` shares these segments across whole-window prediction, five-minute historical pair baselines and conditional nominal storage. `project_days_components` uses the same window kernel and actual local midnight boundaries, including 23/25-hour DST days. Point weather is interpolated on each original geometry-bin/source-hour segment; slicing a segment does not change its power. Electrical assumptions match the incumbent Faiman/isotropic/PVWatts calculation. There is no electrical correction or proxy correction layered onto this raw path.

The native candidate has identity `native_fdir_ssrd_isotropic_faiman_proxy_pvwatts_dc_v2`.
