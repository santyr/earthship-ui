# Qualified AC-day revision schema activation

Solar_PV `4a11744` adds a separate append-only `energy_analytics.daily_ac_snapshots` table and a strict completed-day encoder/store. The source is `Inverter_AC_Evidence_JSON`, scoped to the operator-attested inverter-only/no-bypass topology; it does not write legacy daily rows, EFC, a DC/AC surplus, or any UI Item. A zero-coverage day remains unavailable, not zero load. Retries are idempotent by digest; revised observations append a new revision. Database mutation triggers refuse UPDATE, DELETE and TRUNCATE. The advisory writer role has no insert grant.
