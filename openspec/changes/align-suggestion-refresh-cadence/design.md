# Design

Generation already occurs every five minutes in the scheduled household forecast cycle. Observed 2026-10-29 13:20 advice evaluated at 13:20:41 uses an indoor receipt expiring 13:20:56. Current UI reads every 30 seconds, has opening/visibility refresh but no online refresh, and resets its report to null after a failure. Source validity cannot truthfully be lengthened to eliminate these gaps.

Add a fixed GET notification stream in the existing advice server. A single server watcher on the private state directory notifies connected pages of atomic report replacement and human state/feedback changes; the stream exposes event names only, never private files or original bytes. Close watchers, heartbeats and listeners with the Vite server. The shared advice store subscribes once, coalesces notifications and overlapping reads, polls at 300000 ms for fallback, refreshes on page show/visibility/online and exposes a callable refresh following successful local records. Network failure preserves the validated last report and records refresh status without advancing its original clocks. Stale/expired reporting remains derived from the actual clock and per-domain expiry, including provisional comparison horizon end times. UI age should be visible without increasing the established header height or changing time/date/energy placement.

Verification covers fake-clock cadence, shared subscriptions, actual notification transport, failed reads, cleanup, original expiry, human-state invalidation and stale UI age. A production-shaped immutable UI copy preserves unrelated deployed files and private settings. Native service selectors, timers, model/source inputs and actual equipment remain unchanged.
